🎮 About
This is an experimental prototype that combines the satisfying destruction mechanics of Smash Hit with free-roaming camera movement. Players can explore a warehouse setting and interact with destructible objects around.

✨ Features
Free Camera Movement - Full 3D navigation instead of on-rails movement
Engine: Unreal Engine 5.3.2
Genre: First-Person Destruction/Puzzle
Status: Prototype/Proof of Concept

📝 Notes
This is an early-stage prototype created for experimentation and learning purposes.
